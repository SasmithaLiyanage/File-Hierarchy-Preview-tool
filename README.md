# FileHierarchyTool 📂

A native Windows desktop application built with C# and WinUI 3 that allows developers to design, preview, and physically generate project file structures using a custom lightweight scripting language.

## Key Features

* **Custom Scripting Engine:** Type intuitive scripts to define your entire folder and file architecture.
* **Real-Time Live Preview:** Visually see the directory tree update dynamically as you type in the editor.
* **Direct-to-Disk Generation:** Instantly create the drafted folder hierarchy directly on your hard drive. 
* **Documentation Export:** Download the visual tree hierarchy as a formatted README file to easily include in your project documentation.
* **Pre-Built Templates:** Load standard project architectures directly into the editor and customize them on the fly.

## Tech Stack

* **Framework:** WinUI 3 / Windows App SDK
* **Language:** C# / .NET 8
* **UI/UX:** XAML, Fluent Design System, Mica Backdrop

## 🚀 How It Works

1. **Write:** Select a pre-built standard template or start typing your custom hierarchy syntax.
2. **Preview:** Verify the generated visual tree on the side panel.
3. **Generate:** Click generate or use the built-in terminal command to build the actual folders and empty files on your local machine.
